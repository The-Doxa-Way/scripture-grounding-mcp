# Voiceover script — Garth records, ~2:30 spoken

**How to record:** quiet room, QuickTime Player → File → New Audio Recording
(built-in mic is fine), read naturally and a touch slower than feels normal,
one continuous take is fine — I cut around stumbles, so just repeat any flubbed
line and keep going. Save as `media/vo.m4a` in this repo (create the folder) or
AirDrop it to yourself and tell Claude where it is. Everything visual is mine.

Numbers are written out as words to read. Em-dashes are breath pauses.

---

Ask an AI assistant to quote Isaiah fifty-three, verse five. Word for word.
It answers instantly — confidently — and gets it wrong. Not badly wrong.
Almost right. Which is worse.

The founder of YouVersion — the Bible app with over a billion installs — said
publicly that the best AI models misquote Scripture fifteen to sixty percent of
the time. In our own testing, one model, asked for Hebrews thirteen five,
simply refused to answer at all.

Billions of conversations now happen inside AI assistants. Scripture is
already in those conversations — quoted from statistical memory. For
Scripture, close isn't faithful.

So we built the missing bridge. The Scripture Grounding MCP — an open-source
server that speaks the Model Context Protocol, the standard that connects
tools to nearly every AI assistant: Claude, ChatGPT, Cursor, and beyond. It
has one rule: the model never quotes from memory.

Connect it, and three things change.

First — get passage. The assistant retrieves canonical text, live, from the
YouVersion Platform. The Berean Standard Bible by default. Two thousand
translations with a free key.

Second — verify quote. Hand it any AI-produced quotation, and it runs a
deterministic, word-level comparison against the canonical text — code, not
another model grading its own homework — and returns the verdict, and the
correction.

Third — grounded reply. Real encouragement for a real moment, generated by
Gloo AI Studio's values-aligned models — allowed to quote only the text it
just retrieved.

We measured it. Same model. The same thirty-four passages — narrative,
poetry, prophecy, gospel, epistles. Quoting from memory: sixty-five percent
exact. Grounded: one hundred percent. The methodology, the corpus, and every
raw output are in the open repo — reproducible with the same free keys this
challenge gives every participant. And the limitations are named right next
to the results, because trust is the product. This problem is not solved. It
is now measurable — and materially smaller.

We build Doxa, a prophetic encouragement app, and we run this retrieve-first
pattern in production. Opening the accuracy layer is our answer to the
challenge YouVersion issued. Scripture, present where people already are — in
games, in IDEs, in wearables, in every AI conversation on earth — and word
for word true.

The bridge is built. It's open. Connect it.
