## The frontier nobody named

Billions of people now spend hours a day inside AI conversations — ChatGPT, Claude, Copilot, IDE agents — where Scripture is already quoted, paraphrased, and misquoted daily. YouVersion's founder said publicly that leading AI models misquote Scripture 15–60% of the time.

The gap isn't a smarter model — it's architecture: models quote from statistical memory. So we built the bridge the frontier was missing: a Model Context Protocol server so **the model never quotes from memory again**.

## What it does

MCP is the open standard plugging tools into nearly every major AI surface. Connect this server and any assistant gains:

- **`get_passage`** — canonical text via the YouVersion Platform API (BSB by default; 2,000+ translations with your own key).
- **`verify_quote`** — hand it any quote + claimed reference: it fetches canonical text, diffs it word-by-word, and returns a verdict (exact / minor variance / misquote / misattribution / different_translation) with the correction — code, not a model grading itself.
- **`grounded_reply`** — encouragement for a real moment ("I'm anxious about my future"), generated by Gloo AI Studio under one hard rule: retrieve first, quote only the retrieved text, cite it.
- **`verify_register`** — checks any AI reply for first-person, reassurance-empathy, or companion/personhood language via a shared rule table — code, not a model grading itself. `grounded_reply` runs this on itself before returning, always-on.

Works out of the box, no keys, on the public-domain Berean Standard Bible; add your own YouVersion key for the licensed library. Open source (MIT) — every frontier this challenge names, games to wearables to social, can build on it.

## Measured, not solved

We benchmarked the same Gloo AI Studio call with and without grounding across 34 passages spanning narrative, poetry, prophecy, gospel, and epistles: exact-quote rate 67.6% ungrounded vs 100% grounded (grounded+verify also 100%); misattribution 0% in both. We also checked our own scoring for a hidden bias: none of this run's 11 ungrounded misses were actually accurate quotes of a different public-domain translation (WEB/KJV, checked locally) — the gap is real, not a translation-mismatch artifact. Methodology, corpus, and runner are in the repo — reproducible with free challenge keys.

Named limitations, because trust is the product: cross-chapter ranges are unimplemented; misattribution search is corpus-bounded; grounded generation can still err in the words *around* a quote; the register guard is deterministic regex, not semantic understanding. Grounding makes errors detectable, not plausible-looking: not solved, but measurable and smaller.
