# The Model Never Quotes From Memory

**An open MCP server that makes any AI assistant quote Scripture accurately — built on the YouVersion Platform and Gloo AI Studio.**

## The frontier nobody named

Billions of people now spend hours a day inside AI conversations — ChatGPT, Claude, Copilot, agents inside IDEs. Scripture is already present in that frontier: quoted, paraphrased, and misquoted, every day. YouVersion's founder said publicly that leading AI models misquote Scripture 15–60% of the time, and that the accuracy bar hadn't been met.

The gap isn't a smarter model. It's architecture: models quote from statistical memory. So we built the bridge the frontier was missing — a Model Context Protocol server that means **the model never quotes from memory again**.

## What it does

MCP is the open standard that plugs tools into nearly every major AI surface. Connect this server and any assistant gains:

- **`get_passage`** — canonical text via the YouVersion Platform API (BSB by default; 2,000+ translations with your own free app key).
- **`verify_quote`** — hand it any AI-produced quote + claimed reference: it fetches canonical text, runs a deterministic word-level diff, and returns a verdict (exact / minor variance / misquote / misattribution) with the correction. Verification is code, not a model grading itself.
- **`grounded_reply`** — encouragement for a real moment ("I'm anxious about my future"), generated by Gloo AI Studio's values-aligned models under one hard rule: retrieve first, quote only the retrieved canonical text, cite it.

Works out of the box with no keys at all on the public-domain Berean Standard Bible; add your own YouVersion key for the licensed library. Open source (MIT), so any of the 19 frontiers this challenge names — games, wearables, IDEs, social — can build on it.

## Measured, not solved

The full methodology, corpus, and runner are in the repo and the attached notebook — reproducible with free challenge keys.

Named limitations, because trust is the product: cross-chapter ranges are unimplemented; misattribution detection searches a bounded corpus; grounded generation can still err in the words *around* a quote. Grounding makes remaining errors detectable rather than plausible. This problem is not solved; it is now measurable and materially smaller.
