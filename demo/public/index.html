scripture-grounding-mcp — live demo

The model never quotes from memory.

1. Try a passage

Retrieve canonical BSB text for a reference. Try "John 3:16-17" or "Psalm 23:1-6".

2. Verify a quote

Paste a quote and the reference it's claimed to be from. Try changing a word or citing the wrong verse to see a misquote/misattribution verdict — or try "I can do all things through Christ which strengtheneth me" claimed as Philippians 4:13 to see a different_translation verdict (see the box below).

What about other translations?

Fair objection: this benchmark scored quotes against the Berean Standard Bible (BSB) — maybe the model quoted a different translation accurately, and got marked wrong for it. This benchmark's own ungrounded prompt already names BSB explicitly ("Quote <reference> exactly from the Berean Standard Bible"), so that's still a real miss of what was asked — but it's a different, more forgivable failure than invented wording, and this project measures the difference instead of asserting it away.

Today: verify_quote compares every quote against the closest of three public-domain canons this project ships — BSB, WEB, and KJV — and returns different_translation instead of misquote when a quote misses BSB but is a close (≥0.95 similarity) match for one of the others. Try it in the panel above. Run against this benchmark's own 11 ungrounded misses (zero extra API calls — scored from already-cached output), the honest result was 0 of 11: none of them turned out to be accurate WEB/KJV quotes. The gap is real, not a translation-mismatch artifact — see benchmark/results/RESULTS.md's "Cross-translation check" section.

Implemented and tested, off by default: with your own free YouVersion key, get_passage and verify_quote already work against any one of YouVersion's 2,000+ licensed translations at a time. Extending today's closest-canon comparison to check several of those licensed translations at once — live, via your own key, never a committed fixture — is now built and tested in the open-source repo (a prior pass declined to build this at all pending the founder's own explicit direction, which was then given). It ships gated off by default behind an explicit environment-variable opt-in, pending YouVersion's own written sign-off that this specific use is covered — that request is in. This hosted demo holds no server-side YouVersion credential and stays fixture-only either way (see the repo README); the licensed-comparison path is for self-hosted, bring-your-own-key deployments of this server. YouVersion, please say yes.

3. Try an encouragement

Describe how you're feeling. A relevant passage is retrieved first, then a reply is generated constrained to quote only that passage.

4. Verify the register

Paste any AI reply (or one from above). Checks for first-person language, reassurance-empathy phrasing, and companion/personhood claims — the tool is a signpost, never a companion. If the text quotes Scripture verbatim, name the reference so that quote is exempted from the first-person check.
