scripture-grounding-mcp — live demo

The model never quotes from memory.

An open MCP server + API that retrieves canonical Scripture text and verifies any quote against it — instead of trusting an LLM's recall. Everything below runs keyless on the committed, public-domain Berean Standard Bible (BSB) fixture corpus.

1. Try a passage

Retrieve canonical BSB text for a reference. Try "John 3:16-17" or "Psalm 23:1-6".

2. Verify a quote

Paste a quote and the reference it's claimed to be from. Try changing a word or citing the wrong verse to see a misquote/misattribution verdict.

3. Try an encouragement

Describe how you're feeling. A relevant passage is retrieved first, then a reply is generated constrained to quote only that passage.
